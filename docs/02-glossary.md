# 名詞與時間邊界

## 單位

- **M**：站務排班，所屬值是 `LB01`–`LB12` 車站。
- **T**：檢測排班，所屬值是專業分組，並有 1–5 能力分數與每月固定班別。

## 月班表

CSV 與 Excel 共用的資料概念稱為「月班表」：一列一人，日格以 1–31 號橫向排列。程式中對應 `MonthlySchedule` 與 `EmployeeMonthlySchedule`，不使用 `Wide` 或 `Row` 當作 domain 名稱。

`ScheduleInput` 一次包含：

- `PreviousMonth`：完整上月實際班表；新進人員可不存在。
- `DemandMonth`：本月唯一的人員與需求來源。
- `RestIntervals`：連續的 56 日 R/R1 區間。
- `NonStandardShifts`：非常態班型表；保留班型、代碼與起訖時間，供 CSV 或之後的前端將日格別名解析成 X。

## 班表代號

- `早`、`午`、`夜`：正常班；夜班歸屬其開始日。
- `R`：一般休假，也是「最多連續六日不得無一般休假」的重置日。
- `R1`：國定假日額度的特別休假；不取代上述 R 重置。
- `R休`：人員自行決定本月使用數量的休假；只可安排在目標月的 `R*`。它和 R1 一樣屬於實際休假，但不計入 R/R1 月統計或 56 日額度，也不重置一般 R 的七日規則。
- `R*`：未決定要用 R、R1 或 R休的指定休假請求。
- `R*`、`R1*`、`R休*`：班表中已決定為 R、R1、R休且保留指定休假記號的結果；舊中括號格式仍可讀取。
- `X[HH:mm-HH:mm]`：台北時間的公務事件。

非常態班型是 X 的可維護別名。月班表日格讀到非常態班型的非空白班型名稱或代碼時，會依非常態班型表轉成同日起始的 X；跨午夜仍歸開始日。`早`、`午`、`夜` 維持正常班，不因同名非常態班型而改變。

`SpecialRest` 在 C# 中就是 R1，`LeaveRest` 是 R休；`RequestedRest` 才是 R* 顯示記號。

## 八週區間

`RestInterval` 為含首含尾 56 個日曆日。每人每區間額度為：

- R = 區間內六、日數，固定為 16。
- R1 = 區間檔中列出的國定假日數。

本系統的國定假日不會落在六、日。月份可在月中從 A 區間切換到 B 區間：「月初區間累計」屬於月初所在的 A，「月底區間累計」屬於月底所在的 B。

## 模型時間範圍

- 輸出日期：目標月 1 號至月底。
- 模型日期：目標月 1 號至月底後七天。
- 上月歷史：在職日必須是完整、已決定的整月班表。
- 時區：台北 UTC+8。
