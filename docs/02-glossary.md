# 02. 名詞、代號與時間邊界

所有時間為台北時間（UTC+8）。「一週」固定為**星期一至星期日**。

## 1. 核心名詞

| 名詞 | 定義 |
|---|---|
| 目標月份 | 使用者選擇、需要統計及發布的月份，例如 `2026-08`。 |
| 排班區間 | 從目標月份 1 日起，到**該月最後一天所在週的星期日**止。 |
| 延伸排班日 | 月底之後、但仍在排班區間內的日期；曆法上屬於下個月。 |
| 排班日期 | 班表的一個日期欄。**夜班歸屬其開始日期**。 |
| 正常班 | 早、午、夜三種；實際起訖時間依 M／T 各自的固定設定（見下方第 5 節）。 |
| 工作日 | 該日期狀態為早、午、夜或 X。 |
| 休假日 | 該日期狀態為 R，或已滿足的 R\*。 |
| 實際工作區間 | 一筆正常班或 X 的完整開始與結束時間（日期＋時刻），用於 11 小時休息檢查。 |
| 嚴格候選 | 全部 P0 成立、無 UNASSIGNED，可被選為 Draft 的求解結果。 |
| 缺班分析 | M 嚴格模型無解時，允許班位缺額的分析結果；只能查看，不可發布。 |
| 8 週週期（ScheduleCycle） | 管理者維護的休假週期，含 `start`、`end`、`requiredR`；所有 M、T 共用同一份公司週期表。 |

## 2. 班表代號

| 代號 | 意義 | 算工作日 | 計入 R |
|---|---|---|---|
| 早／午／夜 | 正常班 | 是 | 否 |
| R | 系統安排休假 | 否 | 是 |
| R\* | 使用者指定且**已滿足**的休假；輸出保留 R\* 字樣 | 否 | 是 |
| X | 預先指定的公務、上課、CP、卡班等勤務 | 是 | 否 |
| `{站碼}-{班別}`（例：`LB03-早`） | M 跨站支援：至非本站的同群組車站上班 | 是 | 否 |
| UNASSIGNED | 缺班分析中的未補班位；**只允許出現在缺班分析** | 否 | 否 |

補充：

- 跨站支援的顯示格式為通用的 `{站碼}-{班別}`（如 `LB02-午`）；原規格書以 `LB03-早` 舉例。
- R\* 未被滿足時，該格顯示**實際排定的班別**（早／午／夜等），並在違規清單以
  `GEN-R-01` 標示未滿足的 R\*（決策 D-03）。
- X 歸屬其**開始日期**；跨午夜的 X 只在開始日顯示 X、只算 1 個工作日。
  其結束日期那一格由求解器照常決定（早／午／夜／R／R\* 皆可），僅受 P0 約束（決策 D-01）。

## 3. 連續工作區段

**定義**：連續曆日皆為「早、午、夜或 X」的**最大**區段。R 與 R\* 會切斷區段；班別是否相同不影響。

例：`早, X, 午, R, 夜` → 兩個區段，長度 3 與長度 1。

## 4. M 同班別區塊（僅 M 使用）

**定義**：依日期順序只讀取 M 的**正常班別**（早／午／夜）。R／R\* **不切斷**區塊，
X **完全略過**；遇到不同的正常班別才結束原區塊。區塊的「次數」＝其中正常班的天數。

例：`早, R, 早, X, 早, 午` → 「早 3 次」與「午 1 次」兩個區塊。

## 5. 班別時間與營運資料

### M（站務）

| 項目 | 規格 |
|---|---|
| 班別時間 | 早 06:30–14:30；午 14:20–22:20；夜 22:00–翌日 07:00 |
| 車站 | LB01–LB12，分四個群組：**A**＝LB01–03、**B**＝LB04–06、**C**＝LB07–09、**D**＝LB10–12 |
| 每日需求 | 所有站每日各 1 名早、1 名午；**LB01、LB06、LB08、LB12** 另各 1 名夜。週末與國定假日同樣適用 |
| 外派 | 只有 **LB02、LB04、LB11** 的班位可用外派補足（C 群組無外派站，經業務確認正確，決策 D-02）。外派只記錄班位，不建立假員工列 |
| 人員能力 | 所有 M 人員可上早、午、夜；可在**同群組**車站支援，跨群組選項不存在 |
| 輸出 | 本站顯示早／午／夜；跨站顯示 `{站碼}-{班別}`；另有 R、R\*、X |

### T（檢測）

| 項目 | 規格 |
|---|---|
| 班別時間 | 早 07:00–15:00；午 15:00–23:00；夜 23:00–翌日 07:00 |
| 月班組 | 每人每月明確屬於早、午或夜其中一組；整組按月依 **早→午→夜→早** 輪轉 |
| 專業與能力 | `specialty` 可空白；`ability` 必須為 1–5 的整數 |
| 延伸日班別 | 進入下月的延伸日使用下月班別：**有明確的下月班組資料時以資料為準，否則依輪轉推算**；並檢查夜轉早休假（T-S-MONTH-REST） |

## 6. 排班區間與月底邊界

- 若月底不是星期日（例如是星期三），排班區間仍延伸到該週星期日。
  延伸日**不會拿去營運使用**，其唯一用途是**可行性檢查**：確認月底的安排不會導致
  下個月一開始就違反 11 小時休息、最多連續 6 日、班位需求等硬性規則而無解。
- 延伸排班日適用**全部 P0、班位需求、T-H-01**；但**不參與任何軟規則計分**
  （見 `05-soft-rules.md` 第 7 節，決策 D-13）。
- 本月統計（如 `month_r`）只計目標月份內的日期；8 週週期統計依每個日期實際所屬的週期計算。

## 7. 月初與區間尾端

- 月初的連續工作區段與 M 同班別區塊必須**承接 Published 歷史**
  （例如歷史最後 4 天連續工作，本月 1 日再排工作，區段長度即為 5）。
- 若某區段／區塊到**目標月最後一日**仍在延續（即使在延伸日內就結束），
  該尾端**不計本次軟規則分數**、保存至目標月底的長度，於下次排班承接後再評分；
  但 P0（如最多連續 6 日）照常檢查，且到目標月底已確定超過 5 的部分仍計入違反量
  （見 `05-soft-rules.md` 第 7 節）。
