# 到職日期可留空設計

## 目的

讓既有人員的到職日期可留空，減少日常班表輸入；本月新進人員仍須填寫實際到職日期。

## 語意

- 空白到職日期代表該員工在目標月以前已到職。
- 空白到職日期不免除既有人員提供上月班表的要求。
- 本月沒有上月歷史的人員仍須填寫落在本月內的到職日期，否則輸入無效。
- 同一員工在上月與本月的到職日期須一致，包括同為空白；一邊空白、一邊有值視為不一致。

## 實作

- `EmployeeMonthlySchedule.EmploymentStartDate` 改為 `DateOnly?`。
- CSV 讀寫保留空白；非空白值仍只接受 `yyyy-MM-dd`。
- M/T solver 對空白日期按整月在職處理，既有的新進、到職前日格、休假額度及公平性規則維持不變。
- 同步更新 `docs/03-data-and-validation.md` 與 `docs/10-decisions.md`。

## 驗證

- CSV 可讀取空白到職日期，寫回後仍為空白。
- 上月與本月皆為空白的既有人員可正常求解。
- 到職日期空白且沒有上月歷史時回傳 `InvalidInput`。
- 一邊空白、一邊有日期時回傳 `InvalidInput`。
- 本月新進且填寫日期的既有案例維持通過。
