# 08. 前端功能與互動寬表

本文件只定義功能需求。Blazor 元件不得直接建立 OR-Tools 模型；驗證與求解皆由後端服務執行。
UI 文字一律繁體中文。

流程依決策 [D-20](10-decisions.md)：候選 → 目前班表（無 Draft／Publish 狀態機）。

## 1. 必須提供的功能

| 功能 | 最低需求 |
|---|---|
| 排班準備 | 選擇 M／T 與目標月；顯示人員、T 月班別、歷史、週期、延伸日期及固定設定是否完整 |
| 人員與事件管理 | 維護人員、T 月班別、能力 1–5、R\*、X；支援 CSV 匯入；即時提示格式、重疊與時間衝突（對應 `03` 第 6 節的驗證） |
| 歷史匯入 | 匯入過去的 `schedule.csv`＋`events.csv` 作為歷史快照（初次上線必要，決策 D-05）；供下次排班承接 |
| 規則說明 | 唯讀顯示固定群組、權重與違反量說明；M 顯示 J1 與直接加權合併的 `J4+J5`，T 顯示 J1–J5；第一版不提供開關、排序或參數編輯 |
| 求解控制 | 建立 ScheduleRun；顯示目前處理中的 Priority 群組、已完成群組、OPTIMAL／TIME_LIMIT、候選數及無解狀態 |
| 候選比較 | 比較最多 3 份候選的：未滿足 R\*、外派、跨站、T 出勤／專業／能力、班型（區段／區塊）、公平性、彼此差異率及 Coverage |
| 目前班表 | 選候選為目前班表（同單位同月僅一份）；寬表編輯、修改紀錄／復原、自動存檔與重驗證；可選快照與還原（無審核、無發布） |
| 匯入匯出 | 匯入人員、月班組、事件與歷史；匯出 `schedule`、`coverage`、`violations`（格式見 `06` 第 5 節） |
| 操作者 | 提供「目前操作者」輸入欄，寫入稽核紀錄（第一版無登入的替代方案，決策 D-04） |

## 2. 互動寬表班表管理器

| 需求 | 行為 |
|---|---|
| 表格 | 一人一列、一天一欄；固定員工欄與日期表頭；支援水平／垂直捲動；站別／群組／班組／姓名篩選 |
| 顯示 | M 使用早／小／夜，T 使用早／午／夜，另有 R／R\*／R1／X；M 支援 `{站碼}-{班別}` 跨站顯示；**延伸排班日要有明確標示**；X 可查看完整起訖與說明；R1 與 R 必須清楚可辨（字樣不同，不得只靠顏色） |
| 人工修改 | **只有目前班表可編輯**（快照唯讀）。點選儲存格時，後端回傳該人員該日的可選狀態清單；支援單格修改、自動存檔與復原 |
| 即時規則檢查 | 每次修改重新檢查受影響的人、日期、班位與區段；顯示 P0 是否通過、每條規則的目前指標及白話說明 |
| 問題定位 | **不得只靠顏色**；須標示員工、日期、班位及有意義的規則名稱，並能從違規清單直接跳到對應儲存格 |
| Coverage 聯動 | M 顯示各站班位、外派、缺額；T 顯示每班出勤、專業出勤及能力 4–5 的出勤人數 |
| 休假統計 | 每人顯示：本月 R＋R\*、本月 R1、本週期累積 R＋R\*／需求（requiredR＝16）、本週期累積 R1／需求（requiredR1）、月底後應保留的 R＋R\* 數（reservedGeneralRest，見 `04` GEN-H-04(c)） |
| P0 狀態 | 有任何 P0 違反、缺班、必要資料錯誤時，頁面清楚標示未通過並列出全部原因（無發布按鈕） |

## 3. 顯示細節

- 未滿足的 R\*：儲存格顯示實際排定班別；違規清單列出 `GEN-R-01` 項目並可跳到該格（決策 D-03）。
- R1：目前班表編輯時儲存格可選狀態包含 R1（受 GEN-H-04 的 R1 額度與其他 P0 約束）；
  匯出與重新載入一律保留 `R1` 字樣。
- 跨午夜 X：開始日顯示 X；結束日顯示求解器排定的狀態。查看 X 詳情時顯示完整起訖。
- 外派：不出現在寬表（無假員工列），只反映在 Coverage 的 `external` 欄與候選比較。
- 缺班分析結果以獨立唯讀畫面呈現，明確標示「不可選為目前班表」。
