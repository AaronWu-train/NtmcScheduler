# 資料格式與驗證

## 日期文字格式

所有使用者可見、匯入與匯出的日期文字統一使用零補齊的 ISO 形式：完整日期為 `yyyy-MM-dd`、月份為 `yyyy-MM`；若只顯示月日則為 `MM-dd`。分隔符號一律使用半形連字號 `-`，不接受 `2026/8/7`、`2026-8-7` 或其他地區格式。時間使用 `HH:mm`。

Web 提供的所有 CSV 匯入範本都必須包含 UTF-8 BOM、固定表頭與至少一筆可供改寫的合法範例資料列；範例值參考 `examples/m-2026-09/` 與 `examples/t-2026-09/`，並依下載工作區使用合法站碼、所屬與班別。

## Solver 入口

Solver 不讀 CSV、Excel、DB 或 UI，只接受 typed snapshot：

```csharp
public sealed record ScheduleInput(
    MonthlySchedule PreviousMonth,
    MonthlySchedule DemandMonth,
    IReadOnlyList<RestInterval> RestIntervals,
    NonStandardShiftTable NonStandardShifts,
    WorkspaceShiftTimes? StandardShiftTimes = null,
    MonthlySchedulingSettings? MonthlySettings = null);

public sealed record NonStandardShift(
    string? Name,
    TimeOnly StartTime,
    TimeOnly EndTime,
    string Code);

public sealed record NonStandardShiftTable(
    IReadOnlyList<NonStandardShift> Shifts);

public sealed record MPerpetualSchedule(
    IReadOnlyDictionary<string, IReadOnlyList<ScheduleCell?>> Patterns);

public sealed record ShiftTimePair(TimeOnly Start, TimeOnly End);

public sealed record WorkspaceShiftTimes(
    ShiftTimePair Early,
    ShiftTimePair Afternoon,
    ShiftTimePair Night);
```

`StandardShiftTimes` 為可選欄位，缺省時 Solver 使用硬編碼預設值（M 與 YM：06:30–14:30、14:20–22:20、22:00–翌日 07:00；T 與 YT：07:00–15:00、15:00–23:00、23:00–翌日 07:00）。M、T、YM、YT 的班別時間各自維護。每對起訖不可相同；結束時間早於開始時間視為跨日班。三個班別的時間窗可以互相重疊（班別定義允許重疊，實際排班仍受 CH03 工作區間至少 11 小時休息限制）。

`DemandMonth` 是本月人員資料的唯一來源，不另建員工主檔。上月有、本月沒有的人不排入本月。

`MonthlySettings` 保存本次月份的 R／R1 軟目標；M 的車站固定為 `LB01`–`LB12`，YM 固定為 `Y06`–`Y19`，兩者另保存每站群組、早／小／夜班人數上下限與外援等級。Web 建立月份時只複製同工作區前一個日曆月的設定。YM 沒有前月時使用六組預設：Y06–Y08、Y09–Y11、Y12–Y14、Y15、Y16–Y17、Y18–Y19；各站三班皆為 1–1 且禁止外援。舊 M CLI／舊快照缺少此欄位時仍使用既有 12 站相容預設。

## 月班表 CSV

欄位順序固定：

```text
ID,姓名,所屬,月中開始排班日,月中排班終止日,能力,T月班別,
月初區間累計R,月初區間累計R1,
1,...,31,
當月R,當月R1,R休下限,R休上限,月底區間累計R,月底區間累計R1,本月班數,萬年班表
```

- M：所屬填車站；能力、T 月班別留空。
- T：所屬填專業分組；能力填 1–5；T 月班別填早、午或夜。
- 既有人員的月中開始排班日可留空，代表從目標月第一日起即可排班；有填寫時使用 `yyyy-MM-dd`。
- 月中排班終止日可留空，代表排至目標月最後一日；有填寫時使用 `yyyy-MM-dd`，該日仍可排班，隔日起日格必須空白。舊 CSV 未提供此欄時視為空白。
- 當月不存在的 29–31 號與到職日前必須留空。
- CLI 支援 UTF-8 BOM 與 RFC 式 quoted field；本版不直接讀寫 `.xlsx`。
- `月初區間累計R/R1` 是本月 1 日開始前，在月初所屬 56 日區間內已計入的 R/R1。
- Web 建立 Demand 且找到上月 `★` 時，或之後上傳 previous schedule 時，依員工 ID 將上月 `月底區間累計R/R1` 自動帶入本月 `月初區間累計R/R1`，並將上月 `萬年班表` 帶入本月人員資料。M／YM／T／YT 既有人員在 Demand 內填入的月初 R/R1 為求解正式值，可與上月月底累計不同；兩欄皆留空時才由上月歷史推導。新進人員仍依到職日前日期折抵。
- Web 下載的需求範本不顯示必須留空的求解後欄位：`當月R`、`當月R1`、`月底區間累計R`、`月底區間累計R1`、`本月班數`。M／YM 另移除 `能力`與 `T月班別`；T／YT 移除 `萬年班表`。
- Web 下載的歷史班表範本不顯示 `能力`、`當月R`、`當月R1`、`R休下限`、`R休上限`、`月底區間累計R`、`月底區間累計R1` 與 `本月班數`。T／YT 能力依工作區與員工 ID 從員工列表帶入，找不到時使用 1。
- 匯入依表頭名稱對位，範本省略的既有欄位視為空白。現行完整格式為 48 欄；也接受沒有 `萬年班表` 的 47 欄格式、沒有 `月中排班終止日` 的舊版 47／46 欄格式，以及同時沒有 `月中排班終止日` 與 R休下限的舊版 46／45 欄格式；每組雙數分別為有／無 `萬年班表` 欄。現行 Web 下載格式為 M／YM 46 欄、T／YT 47 欄；缺少的 R休下限視為 0。
- 歷史班表的當月 R/R1、當月指定 R休、月底區間累計 R/R1 與本月班數由程式依日格自動計算。若月底所屬 56 日區間從上傳月份以前開始，CSV 的月初 R/R1 可留空，系統改依同工作區、前一個日曆月 `★` 採用班表中同員工的月底累計回推；兩者都無法取得時阻擋匯入，不得當作 0。
- `月底區間累計R/R1` 是截至本月最後一日，在月底所屬 56 日區間內已計入的 R/R1。
- `R休下限` 與 `R休上限` 在需求月分別表示 R休 使用下界與上界；匯入仍接受舊欄名 `當月指定R休下界`、`當月指定R休`。舊資料或 CSV 沒有下限時視為 0，兩者必須為非負整數且下限不得大於上限。歷史班表不必提供，由程式依日格重算實際 R休數，沒有 R休時為 0。
- `萬年班表` 只供 M 填模板代號；本月留白時承接上月同員工代號，本月有值時覆蓋上月。T 必須留空。舊版 CSV 沒有此末欄仍可讀取，輸出一律包含此欄。Web 匯入 demand CSV 時同樣：留白或舊版無此欄，從目前選定的上月班表補代號；CSV 有值則覆蓋。

### 日格

可用值：空白、`R`、`R1`、歷史用的 `R休`、`R*`、`R1*`、`R休*`、相容舊格式 `R*[R]`／`R*[R1]`／`R*[R休]`、`X[08:30-17:30]`、`X[08:30-17:30|日一]`、非常態班型表中的任一名稱或代碼、M 的 `LB01早`（也接受簡寫 `1早`；站號為 1–12）、YM 的 `Y06早`（也接受簡寫 `6早` 與 `6早SM`；站號為 6–19）、T 的 `早`。

班表中的 `R*`、`R1*`、`R休*` 分別表示已決定的指定 R、R1、R休，輸出一律使用尾綴星號。本月需求的 `R*` 仍表示尚待 Solver 決定；本月需求亦可直接固定未標示 R* 的 `R休`。

M 午班輸入同時接受 `LB01小`／`1小` 與舊稱 `LB01午`／`1午`；YM 同時接受 `Y06小`／`6小` 與 `Y06午`／`6午`。M/YM 輸出一律正規化為不含前綴的站號簡寫；T 午班仍使用 `午`。

X 的結束時間小於或等於開始時間時，視為隔日結束；時長不得超過 24 小時。若有註記，格式固定為 `X[HH:mm-HH:mm|註記]`；註記在 `|` 後、去除前後空白後必須為 1–500 字，空註記非法。純 `X[時間]` 仍合法，且不會依時間自動反查班型註記。

### M／T 固定班

M 需求編輯器的固定正常班可填任一 LB 站。跨所屬三站群組的固定班是人工指定跨群組支援，仍為正常工作，會計入指定站點的班位人力；只有這些固定格可跨群組，Solver 對空白格仍只會在所屬三站群組自動排班。

T 的固定正常工作可填早、午或夜，不必等於該列 `T月班別`；不同班別是有效輸入，並計入月班別不一致（`NonMonthlyShift`）軟規則。

Web 需求編輯器日格快捷選單與顯示契約見 `08-frontend.md`。CSV 邊界仍保留固定 1–31 日與完整資料。

## M 八週萬年班表 CSV

```text
萬年班表,1,2,...,56
LB01-1,3午,3午,R,...
```

- 第一欄是唯一模板代號，後續固定為第 1–56 日；每日可留白、填 `R` 或 M 正常工作。空白表示該日不提供 hint；輸入可為完整／簡寫站碼及早／午（小）／夜，下載輸出以站號簡寫（如 `1早`）表示正常班。
- 不匯入外派彙總列或統計欄。模板工作必須位於引用員工的三站群組，且該站班具有正需求。
- 模板第 1 日對應每個 56 日、16R 八週區間的第一天；跨入下個區間時重新從第 1 日循環。
- 模板只供 `CpModel.AddHint` 引導 hard-only 初始搜尋，不固定變數、不新增違反量。固定日格與 R* 不套 hint；歷史邊界不相容時由 CP-SAT 修復。

## 非常態班型 CSV

- `班型` 可填同一代碼的多個名稱，使用半形分號 `;` 分隔；各名稱皆可在列表選取及匯入，輸出保留實際選取的名稱。
- 名稱、代碼在整份設定內不可互相重複；`早`、`午`、`小`、`夜` 為一般班型保留字，不可作為非常態班型名稱。
- YM／YT 的非常態班型輸出註記使用 `名稱(代碼)`，重新匯入時亦接受此格式。

固定三欄，時間分隔符號為半形 `~`：

```csv
班型,時間,代碼
早一,06:30~14:30,0635
,08:00~16:00,0805
日一,08:30~17:30,0837
夜一,22:30~06:30,2235
```

- `代碼`、`時間`必填；`班型`可留空。
- 代碼不可重複；非空白班型名稱不可重複；名稱與代碼也不可互相重複，避免日格查表結果不唯一。
- 日格可填非空白班型名稱或代碼，讀入後轉為 `WorkEvent`；若 `班型` 有值則輸出註記使用班型名稱，否則使用代碼。候選、歷史與下載輸出在有註記時正規化為 `X[HH:mm-HH:mm|註記]`，沒有註記時仍為 `X[HH:mm-HH:mm]`。
- `早`、`午`、`夜`日格優先解讀為 T 正常班；同列代碼仍可用來指定 X。

## 八週區間 CSV

```text
區間開始日期,區間結束日期,國定假日日期
2026-07-20,2026-09-13,2026-08-14
2026-09-14,2026-11-08,2026-09-18;2026-10-12
```

每區間必須剛好 56 日；相鄰區間必須連續、不重疊、無缺口。國定假日必須在所屬區間內且為週一至週五。Solver 建模範圍內的每天必須剛好落在一個區間。

## 歷史、新進與累積

- 既有人員必須在上月班表有整月已決定歷史，並提供上月底 R/R1 累積與正常班次數。
- 月中開始排班日留空者視為整月皆可排班，仍須提供上月班表；沒有上月歷史者必須填寫落在本月內的月中開始排班日。
- 本月有、上月沒有，且到職日在本月內，視為新進。
- 到職日早於本月卻無上月歷史，為 `InvalidInput`。
- 新進人員在到職日前，以區間內已經過的六、日數當作已計 R，已經過的國定假日數當作已計 R1。
- 月中到職者不參與整月公平性比較，但到職後仍適用每日規則與個人月目標。

## 輸入錯誤

Solver 不丟出業務驗證例外；回傳 `SolveStatus.InvalidInput` 與 `InputError(Field, Message)`。主要錯誤包含：

- 月份不連續、重複 ID、必要欄位缺失。
- 同一員工的上月與本月月中開始排班日不一致，包括一邊空白、一邊有值。
- M／YM 站務欄位與 T 檢修欄位混用，或 T 能力、月班別無效。
- 歷史日格缺失、仍為未決定 R*、或固定工作間隔不足 11 小時。
- R休上下界為負數、下界大於上界，或固定 R休數超過上界。
- 日格在月份外、到職日前非空白、X 時間或班別不合法。
- 八週區間天數、連續性、假日日期或覆蓋範圍錯誤。
- M／YM 萬年班表代號重複、不是 56 日、格值非法、引用不存在的模板，或模板工作不在員工合法站群／正需求班位。
